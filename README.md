# Habit Tracker

Single-user habit tracking PWA. See `CLAUDE.md` for project rules and
`design_handoff_habit_tracker/README.md` for the design spec.

## Stack
React + TypeScript + Vite (`vite-plugin-pwa`) + Tailwind CSS + Dexie (IndexedDB) + Chart.js.

## Development
```
npm install
npm run dev
```

## Build
```
npm run build
npm run preview
```
